# Мои Цели — Динамические обои Liquid Glass

Первая пробная версия генератора обоев для iPhone и iPad.

## Разрешения
- iPhone 17 Pro: 1206 × 2622 px
- iPad Pro 12.9" (M1): 2048 × 2732 px

## Как использовать сейчас
1. Открой файл [index.html](https://github.com/ScreekBag/moi-celi/blob/main/index.html) на устройстве (или скачай и открой в Safari).
2. Выбери разрешение кнопкой снизу.
3. Нажми «Скачать PNG» и установи картинку как обои (Фото).

## Автоматическое обновление (после деплоя на Vercel)
После заливки на Vercel будет доступна прямая ссылка на PNG.

### Команда в Shortcuts
1. Создай новую Команду.
2. Действие: **URL** → вставь ссылку на картинку.
3. Действие: **Получить содержимое URL**.
4. Действие: **Установить обои** → Выбери Экран блокировки (и/или Домашний), отключи «Показывать предпросмотр».

### Автоматизация
1. Вкладка Автоматизация → + → Время дня.
2. Повторять ежедневно, Выполнять сразу.
3. Запустить команду выше.
4. Обязательно выключи «Спрашивать перед запуском».
